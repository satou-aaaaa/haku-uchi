# 拍うち

ことばの拍（はく）に合わせて、1拍に1回タップする音ゲーです。小さい「っ」や「ん」、のばす「ー」も1拍。遊ぶうちに、日本語の拍の数え方が身につきます。

- 遊ぶ: <https://satou-aaaaa.github.io/haku-uchi/>
- 今日の5語（だれでも同じ）・上級（今日の一句、5・7・5）・とことん（好きなだけ）・練習
- テンポは3段、下読み（区切りを先に見せる）あり。音と指のずれを合わせる画面つき
- 記録はブラウザの中だけ。外へは何も送りません。音もページの中で作っています
